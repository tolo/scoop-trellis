# Scoop bucket: trellis

Windows [Scoop](https://scoop.sh) bucket for the [Trellis](https://github.com/tolo/trellis) CLI.

## Install

```powershell
scoop bucket add trellis https://github.com/tolo/scoop-trellis
scoop install trellis
```

Manifests under `bucket/` are updated automatically on each Trellis release.
